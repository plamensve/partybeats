# PartyBeats 🎶

**Твоят глас. Нашият ритъм.** Статичен прототип на музикален плейлист за фирмено коледно парти, предназначен за хостване в GitHub Pages.

## Функционалности (v1)

- 🎄 Коледна тема и responsive дизайн за телефон/компютър.
- ➕ Добавяне на YouTube песни (линк, заглавие, изпълнител, категория, име на предложилия).
- 👍 / 👎 Гласуване (възможност за промяна или отменяне на гласа).
- 🏆 Класация по точки: харесвания минус нехаресвания.
- 🔎 Търсене, филтри за коледни/парти песни и сортиране.
- ▶️ Вграден YouTube плейър (когато видеото позволява вграждане) и директен линк към YouTube.
- 📥 CSV експорт на песните в реда на класацията.
- 💾 Запазване на добавените песни и гласовете чрез localStorage.
- 🧪 Демонстрационни песни и фиктивни стартови гласове; бутон за нулиране.

## Важно за демото

**Няма сървър, база данни или реална регистрация.** GitHub Pages обслужва само статичните файлове. Данните се съхраняват единствено в *текущия браузър* и **не се споделят между колеги или устройства**. Демо гласовете са примерни, не реални гласувания. Не използвайте това издание за окончателен колективен плейлист.

## Стартиране

Може да отворите директно index.html или локално да пуснете:

~~~bash
python -m http.server 8000
~~~

След това отворете http://localhost:8000.

## GitHub Pages

Repository → **Settings → Pages** → Build and deployment: **Deploy from a branch** → Branch: **main**, Folder: **/(root)** → Save.

При успешно публикуване адресът обичайно е https://plamensve.github.io/partybeats/ (проверете Pages за окончателния адрес).

## Предстояща функционалност

За реално групово гласуване: Supabase Postgres, потребителски профили (Supabase Auth), уникален глас за песен на потребител, правила на ниво ред (RLS), ограничен достъп за колеги и роли за модериране. Настоящият интерфейс е направен без build стъпка, за да остане съвместим с GitHub Pages.

## Технологии

Vanilla HTML, CSS и JavaScript, без framework, build tools или външна база данни. Google Fonts и миниатюри от YouTube се зареждат от външни сайтове.
